# Sistema de Gestión de Expedientes Académicos

## Descripción

Sistema web para la gestión de expedientes académicos y validación de tesis.

El sistema permite que los estudiantes registren y gestionen sus expedientes,
los docentes revisen los documentos y emitan un dictamen, y los administradores
supervisen el proceso.

## Tecnologías

### Frontend
- React

### Backend
- Node.js
- Express

### Base de datos
- MySQL

### Control de versiones

- GitHub
